# 📋 Codey Community Roadmap

Welcome to the public roadmap for **Codey**! This document tracks our active development, future plans, and completed milestones. We value community feedback, so please feel free to request features or join the discussions.

---

## 🟢 In Progress (Next Release: v3.6.0)

We are actively working on these features. Expect them in the upcoming minor updates.

*   **🧩 Enhanced MCP Server Integration**: Native support for more lazy-loaded Model Context Protocol (MCP) servers with automatic schema parsing and sandboxed execution.
*   **⚡ Speed Optimizations**: Faster UI rendering on session loads and optimized caching for large file tree indexing in Tauri.
*   **🎨 Dynamic Theme Editor**: A visual editor inside settings to create and share custom color schemas (expanding on the catppuccin, vercel, and amoled themes introduced in `v3.5.1`).
*   **🗣️ Real-time Audio/Voice Input**: Connect voice synthesis/speech-to-text to talk directly to your coding assistant.

---

## 🟡 Planned (Q3 - Q4 2026)

High-priority features slated for development.

*   **🔄 Bidirectional Git Sync**: Seamlessly stage, commit, and push modifications directly from Codey's interface with automated AI commit messages.
*   **☁️ Collaborative Code Sessions**: Real-time collaborative coding (like Live Share) with end-to-end encryption.
*   **🤖 Advanced Agent Swarms**: Multi-agent collaboration where specialized sub-agents work concurrently on tests, frontend components, and database migrations.
*   **📱 Codey Companion Mobile App**: Monitor long-running agent workflows, review diffs, and approve code execution remotely from iOS/Android.
