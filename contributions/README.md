# 🤝 Codey Community Contributions

Welcome to the Codey Community shared directory! This section is dedicated to sharing custom configurations, automations, and templates that extend the capabilities of the Codey AI coding agent.

By sharing your custom setups, you help other developers build faster and work smarter.

---

## 📂 Shared Categories

| Directory File | What it contains | How to use |
| :--- | :--- | :--- |
| [**🤖 Agent Templates**](./agent-templates.md) | JSON definitions of custom agents | Add to your local `agents` list in `~/.codey/config.json` |
| [**🧩 Prompts & Skills**](./prompts-and-skills.md) | Modular markdown instructions and prompt scripts | Install files into your `~/.codey/skills/` directory |
| [**🔗 n8n Workflows**](./n8n-workflows.md) | Automation triggers and webhook node blueprints | Import JSON workflows directly inside your n8n workspace |

---

## 📤 How to Contribute

If you'd like to share a template, prompt, skill, or workflow with the community:

1. **Fork** this repository.
2. Edit the matching file in the `contributions/` folder:
   - Append your item to the list.
   - Use the same formatting style (markdown headers, code blocks, tables).
   - Optional: Add your name and a link to your GitHub profile for credit!
3. Submit a Pull Request.

*Before submitting a PR, make sure your configurations are sanitized. Do not include any private tokens, passwords, API keys, or custom personal credentials.*
