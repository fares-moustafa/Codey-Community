# Security Policy

We take the security of Codey and our community seriously. Thank you for helping us keep Codey safe and secure!

## Supported Versions

Currently, security updates are actively provided for the following versions:

| Version | Supported |
| :--- | :--- |
| Latest release (`v3.x` / `v4.x`) | Yes |
| Pre-releases (`beta`, `dev`) | Best effort |
| `< v3.0` | No |

## Reporting a Vulnerability

**Please do not report security vulnerabilities via public GitHub issues.**

If you discover a security vulnerability, please report it privately by sending an email to **[faresmoustafa.dev@gmail.com](mailto:faresmoustafa.dev@gmail.com)**.

Please include the following details in your report:
1. **Description**: A detailed description of the vulnerability and its potential impact.
2. **Steps to Reproduce**: A proof-of-concept (PoC) or clear steps to reproduce the issue.
3. **Environment**: The OS, Codey version, and configurations used during your testing.
4. **Remediation**: If you have a suggested fix, please include it in your email.

We will acknowledge receipt of your report within **48 hours** and provide a tracking update. Once validated, we will work on a fix and release it in a timely manner. We request that you follow responsible disclosure guidelines and refrain from disclosing the vulnerability publicly until a fix has been released.

Thank you for your cooperation in keeping Codey secure!
