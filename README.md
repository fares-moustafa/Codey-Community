## The idea

**Their advantages. Your model.**

Every capability the others lock to their own models — agents, tools, browser, design — Codey runs on any model you already pay for.

It doesn't stop at describing work. It delivers it: files changed, tests run, a deck built, a spreadsheet cleaned, a board that tracks itself. Code and the rest of your work live in the same workspace, with the same agents and the same permissions.

Desktop, terminal, and browser are three windows onto one engine, and your model follows you between them.

---

## The leap from opencode

**Same lineage. A different ceiling.**

Codey is built on the opencode foundation — agents, sessions, tools, providers, MCP, a terminal-first soul — and takes it to a second level: complete, local-first AI production.

| opencode gave you | Codey makes it |
|:---|:---|
| An agent that edits code | A team that ships products |
| Plan mode as a text list | **Blueprint** — a living board where every task is a ready prompt with its own session, tracked from idea to done |
| Two assistants | **Six specialists by name** — Prometheus builds, Athena plans, Scout maps, Iris edits, Matis ships apps, Hermes runs the office |
| Coding as the only job | **Three modes** — Co-Pilot for focused coding, Autopilot for whole apps, Workpilot as a full productivity surface for everything that isn't code |
| MCP servers you wire yourself | **Six tool servers built in** — Browser, Docs, PDF, Writer, Sheets, Slides |
| Work split across apps | **25 agent CLIs in one workspace** — the tools you already use, detected, connected, and streamed side by side |
| Style left to the model | **34 design languages as a contract** — every artifact must bind to its tokens |
| Edits attempted once | **`apply_patch`** — a multi-syntax patch engine with tiered context matching, on every model |
| Work while you're at the keyboard | **Scheduled tasks** — run nightly, weekly, on repeat |
| Local-first as a stance | **Local-first as a guarantee** — zero code uploaded, no mystery bill |

The through-line: opencode automates the edit. **Codey automates the delivery.**

## The workflow

**Ask once. Wake up done.**

| | | |
|:--|:--|:--|
| **01** | **Plan.** | Drop one sentence. It becomes an ordered board of steps. |
| **02** | **Build.** | Agents execute — code, files, browser, docs — every step in its own session. |
| **03** | **Review.** | The agent checks its own work — tests run, quality gate passed — before anything reaches you. |
| **04** | **Deliver.** | Finished work lands in your folder. Rerun any step, any time, with any model. |

**Three modes.**

- **Co-Pilot** — you drive. Codey edits with your approval, one step at a time.
- **Autopilot** — say what you want built. Matis plans it, codes it, polishes it, end to end.
- **Workpilot** — a complete productivity surface, not a coding sidecar. Hermes handles research, documents, spreadsheets, slides, PDFs, browsing, and automation, with the same agents, tools, and permissions as the code side.

**Permission at every gate.** Answer with y / a / n, allow · ask · deny per tool group, per project. Subagents inherit rules they cannot escalate.

## Inside the workspace

**Blueprint.** 
A task board per project. Every card carries its full prompt and opens its own session, and the card moves itself as work progresses. Reorder or rename a task and its session follows. An agent can write a discussed plan onto the board, but only after you approve the split.

**Browser.** 
One managed Chromium that you and the agent share: the tab in the side panel is the tab it drives. Inspect selects the component you meant. A confirmed selection goes into your next message — an image for vision models, a readable snippet for text ones. Pages you build open from disk in the same panel.

**Design systems.** 
34 languages, each with its own token contract. Attach one and the agent works within it — its spec, its variables, its rules — so output keeps the same look instead of drifting per run. Pattern and palette only, never another company's brand.

**Documents and media.**
Word, PowerPoint, Excel, PDF, and video open inside Codey, and large files load instantly. The output is the file itself: a cleaned spreadsheet, a deck from your notes, a filled PDF, a draft you can send.

**Agents and subagents.**
Six specialists by name, plus custom agents and subagents scoped globally or per project. Any agent's system prompt, model, and tool rules are inspectable before you use it.

**Skills and MCP.**
70 skills, installed from a GitHub link, discovered at global and project scope. Every MCP dialect works by copy-paste, and its tools appear the moment a server connects.

**Scheduled tasks.**
Run work on a schedule — nightly, weekly, repeating — against any project, and read the result when you're back.

**Context and prompting.**
A breakdown shows where tokens went — input, output, reasoning, cache, summary — with cost always visible, and long sessions are summarized rather than cut short. and Improve Prompt rewrites a prompt for the model you're on.

## What it's for

- **Refactor a codebase you inherited.** Scout maps it, Athena splits it, Prometheus lands it, tests green before you review.
- **Ship an app from one sentence.** Matis builds it end to end, on brand, on your machine, in the model you already pay for.
- **Turn a meeting into a board.** The plan becomes tasks with real prompts, each running in its own session.
- **Fix a screen from a screenshot.** Select the region in the shared browser; it arrives as an image to a vision model, a snippet to a text one.
- **Produce the deliverable, not the draft.** A spreadsheet cleaned, a deck from your notes, a PDF filled, a document ready to send.
- **Run the routine work nightly.** Tests, reports, migrations, digests — queued at midnight, waiting in the morning.
- **Delegate work that isn't code.** Research, compare, summarise, prepare — Hermes handles it in the same workspace, while you keep coding.
- **Stay un-locked.** Switch providers mid-task. Run the agent CLIs you already use inside Codey. Change models tomorrow without losing your work.

## Install

**One command.**

```bash
curl -fsSL https://codeyai.space/install | bash
```

```bash
cd ~/projects/my-app && codey
```

**Desktop.** macOS (Apple Silicon and Intel) and Windows (x64 and ARM64) from [releases](https://github.com/fares-moustafa/Codey-Community/releases/latest). **Linux** runs the CLI and TUI — the command above is the supported path.

**Updates.** `codey upgrade`. It also checks, rolls back, and switches channels on its own.
