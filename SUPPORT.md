# Support Guide

Welcome to the Codey support guide! Whether you are troubleshooting installation issues, configuring Model Context Protocol (MCP) servers, or looking to customize your agents, this document outlines the best channels for getting help.

## 🏛️ Support Channels

### 1. 💬 GitHub Discussions (Recommended)
For general questions, configuration help, and discussing ideas, please use [**GitHub Discussions**](https://github.com/fares-moustafa/Codey-Community/discussions). 
* **Q&A**: If you are stuck on installation, CLI arguments, or environment variables.
* **Show & Tell**: Share your custom prompts, theme configurations, or n8n automation workflows.
* **Ideas**: Discuss potential features with the community before submitting a formal request.

### 2. 🐛 GitHub Issues
Use [**GitHub Issues**](https://github.com/fares-moustafa/Codey-Community/issues) exclusively for:
* **Bug Reports**: Fully reproducible bugs, errors, or application crashes.
* **Feature Requests**: Formally structured requests for new features.

*Please check the existing issues to see if your bug/feature has already been reported before creating a new one.*

### 3. 📧 Email Support
For private matters, security vulnerability disclosures, or organizational inquiries, contact us directly at:
* **[faresmoustafa.dev@gmail.com](mailto:faresmoustafa.dev@gmail.com)**

## 🛠️ Diagnostics Checklist

Before asking for help, please verify the following:

1. **Check version**: Make sure you are on the latest release of Codey:
   ```bash
   codey upgrade
   ```
2. **Read the Docs**: Verify if your issue is covered in the [Documentation](./docs) (specifically [getting-started.md](./docs/getting-started.md) or [installation.md](./docs/installation.md)).
3. **Capture Logs**: If Codey crashes, capture any logs output in the console. You can run Codey with standard debug environment variables if applicable.
